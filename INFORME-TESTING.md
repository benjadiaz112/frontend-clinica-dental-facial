# Informe de testing

La suite vigente contiene dos pruebas unitarias de funciones puras ejecutadas con Vitest. Sus archivos, entradas, resultados y límites se describen en [docs/PRUEBAS.md](docs/PRUEBAS.md).

```bash
npm test
```

El catálogo y el formulario gestionan el estado directamente en sus componentes. El cambio de entorno conserva el funcionamiento de la clínica y reduce el alcance automatizado a las dos validaciones indicadas. Los porcentajes y resultados de la suite anterior no se presentan como resultados de esta versión.
