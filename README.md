# Clínica Aura

Proyecto académico de Benjamin Diaz y Bikenson Fenelus para la Evaluación Parcial 3.

- [Backend](backend/README.md): Java 21, Spring Boot, cinco microservicios, Gateway, Swagger y MySQL con Docker.
- [Frontend](frontend/README.md): Next.js, React, catálogo, sesión por rol y reservas.
- [Documento de integración](backend/ARQUITECTURA.md): puertos, endpoints, autenticación y flujo de datos.
- [ERS del Parcial 3](frontend/ERS.docx) con los requisitos y el alcance de la aplicación actual.
- [Manual de usuario](frontend/docs/MANUAL-PARCIAL-3.md) con el recorrido y capturas.
- [Pruebas del backend](backend/PRUEBAS.md) con los comandos de JUnit y Mockito.

Para ejecutarlo en localhost, inicia MySQL con Docker Compose, compila los servicios con Maven y ejecuta el script de arranque. Luego inicia Next.js desde `frontend` y abre [localhost:3000](http://localhost:3000). La guía del backend incluye los comandos y cómo crear las cuentas de demostración.
